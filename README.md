# 翻书 Flipbook

纯前端的 EPUB 电子书繁简双向转换工具。所有处理都在浏览器本地完成，文件不会上传到任何服务器。

**在线体验**：<https://peteliao.github.io/flipbook/>

## 功能特性

- **多文件批量处理**：支持单本或多本 `.epub` 文件拖拽与多选，支持批量排队转换与一键打包下载全部（`.zip`）。
- **真实图书封面提取**：自动读取 EPUB 2 / EPUB 3 规范中的封面图并精致呈现。
- **自动识别文字类型**：对前几章正文抽样分析，智能判断繁体/简体为主并给出置信度。
- **方向与词汇选项**：
  - 自动识别 / 繁 → 简 / 简 → 繁
  - 可选地区词汇转换（記憶體 ↔ 内存、滑鼠 ↔ 鼠标）
  - 可选标点风格转换（繁体直角引号 `「」` `『』` ↔ 简体弯引号 `“”` `‘’`）
- **即时对比预览**：支持在转换前或转换后随时打开预览弹窗，对照查看正文样例文本的转换前后效果。
- **严格遵循 EPUB 规范**：
  - 同步更新 OPF `<dc:language>`（`zh-CN` / `zh-TW`）与章节 `<html lang="..." xml:lang="...">`，保障阅读器字形渲染与字体选择正常。
  - 正确转换正文、目录（NCX / EPUB 3 Nav）、图片 `alt` 属性及 OPF 元数据（书名、作者、简介等）。
  - 输出标准 EPUB（`mimetype` 为首个 `STORE` 非压缩条目）。
  - 内置 XML 实体预处理，杜绝自闭合标签损坏；主动拦截 DRM 加密书籍并给出友好提示。
- **极速性能与低内存开销**：
  - **首屏体积暴降 98%**：主线程 entry 仅 **14 KB**，OpenCC 词典全量移至后台异步加载。
  - **Web Worker 异步运算**：解包、词典匹配、DOM 遍历与打包在后台 Worker 执行，UI 界面全程 120fps 丝滑不卡顿。
  - **原地覆写机制**：避免重打包时对高清图片和字体等非文本资产进行内存全量深拷贝，消除移动端 OOM 崩溃隐患。
- **现代化视觉与主题**：
  - 支持浅色 / 深色 / 跟随系统主题三态无缝切换，持久化记忆。
  - 全局窗口防误拖拦截，防止意外拖出 dropzone 导致浏览器打开文件。

## 快速开始

```bash
npm install
npm run dev      # 启动开发服务器 http://127.0.0.1:5173
npm run build    # 生产构建，产物输出到 dist/
npm test         # 一键运行全自动繁简与规范回归测试
```

## 测试

```bash
npm test                                    # 执行 Node 环境下的全套自动化测试
node scripts/make-test-epub.mjs             # 重新生成繁体 / 简体两本测试书到 test/
```

## 技术架构

- `src/epub.ts`：EPUB 标准解析器与转换管线。支持封面提取、DRM 拦截、实体转义、属性文本替换、语言代码联动与原地增量压缩打包。
- `src/detect.ts`：繁简字符集采样与单向字符置信度判定。
- `src/worker.ts`：独立 Web Worker 后台计算线程，完全隔离主线程 UI。
- `src/service.ts`：Worker 与主线程的 Promise 通信桥梁，具备无缝的回退（Fallback）容灾能力。
- `src/main.ts`：UI 交互控制、批量队列管理、明暗主题控制与预览弹窗。
